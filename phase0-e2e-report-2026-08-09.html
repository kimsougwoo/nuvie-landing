5. 현재 차단 게이트

  • Vercel 프로젝트에 환경변수가 없습니다. vercel env ls 결과 0건입니다.
  • 필요 값: NOTION_TOKEN(보안 입력), NOTION_CRM_DATA_SOURCE_ID, NUVIE_SITE_ORIGIN, NOTION_VERSION.
  • Notion integration에 CRM 데이터베이스 페이지 생성 권한을 부여해야 합니다.
  • PortOne V2 전환에 필요한 지속성 재고 잠금·서버 결제 검증·웹훅 멱등 처리·환불 경계는 아직 활성화하지 않았습니다.

6. 후속 작업 순서

  1. Vercel Preview에 위 환경변수 설정 및 Notion integration 권한 연결
  2. Preview에서 UTM 유입 → 동의한 관심접수 → Notion 한 행 생성 확인
  3. 동의 누락·연락처 누락·honeypot·외부 Origin·Notion 오류 케이스가 성공으로 표시되지 않는지 확인
  4. GA4·Clarity·Meta 이벤트에 이메일·전화번호가 포함되지 않는지 확인
  5. Preview 표면 재조회 후 Production 배포
  6. 그 다음에만 Phase 1 착수: PortOne V2 서버 검증, 시간대 잠금 저장소, 웹훅 멱등, 환불 처리, 아워플레이스·네이버예약 충돌 검증
